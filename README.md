# Foodie Quiz! 🍣

A cute, colorful, interactive food quiz built with HTML, CSS, and JavaScript.

## Play the quiz

[Open Foodie Quiz!](https://cj2919.github.io/mbti--quiz/)

## About the project

This group project stores quiz questions in an easy-to-edit JavaScript array. The quiz currently contains the first teammate's question about where sushi originated. Each teammate can add their own question to the `questions` array in `script.js`.

## Project files

- `index.html` — quiz page structure
- `style.css` — colorful food-themed design
- `script.js` — questions, scoring, feedback, and button behavior
